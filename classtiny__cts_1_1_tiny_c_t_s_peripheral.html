Detailed Description

The server side (peripheral role) of the Bluetooth stack of the operating system: offers the Current Time Service (0x1805) with the characteristics Current Time (read, notify, write), Local Time Information (read, write) and Reference Time Information (read), and advertises it.

The values are not stored: the requests of the clients are given to a TinyCTSPeripheralHandler. BlueZ (Linux), CoreBluetooth (macOS) and WinRT (Windows) each implement it; TinyCTSServer uses it. Get an object with ctsCreatePeripheral().
