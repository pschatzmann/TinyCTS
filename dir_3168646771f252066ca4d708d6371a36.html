Files

 		TinyCTSClient.h
 The Current Time Service client: NimBLE-Arduino (ESP32, nRF5), BlueZ (Linux), CoreBluetooth (macOS), WinRT (Windows) ArduinoBLE or the BLE library of the Raspberry Pi Pico W core, see TinyCTSConfig.h.
 		TinyCTSClientBase.h
 The logic of the Current Time Service client, independent of the Bluetooth stack: decoding of the characteristics and the clock that runs between two updates. The classes for NimBLE and for the Raspberry Pi Pico (W) derive from it.
 		TinyCTSConfig.h
 Selects the Bluetooth stack: the BLE library of the Raspberry Pi Pico (W) core (BTstack) on the RP2040/RP2350, BlueZ on Linux (needs GLib/GIO), CoreBluetooth on macOS, WinRT on Windows, NimBLE-Arduino everywhere else. ArduinoBLE is used on the Arduino boards that are made for it (mbed cores, Uno R4 WiFi, Nano 33 IoT, MKR WiFi 1010); define TINY_CTS_USE_ARDUINOBLE to use it on another board. Define TINY_CTS_USE_NIMBLE, TINY_CTS_USE_PICO_BLE, TINY_CTS_USE_BLUEZ, TINY_CTS_USE_COREBLUETOOTH or TINY_CTS_USE_WINRT to choose yourself. TINY_CTS_USE_DESKTOP is defined for the last three.
 		TinyCTSServer.h
 The Current Time Service server: NimBLE-Arduino (ESP32, nRF5), BlueZ (Linux), CoreBluetooth (macOS), WinRT (Windows) ArduinoBLE or the BLE library of the Raspberry Pi Pico W core, see TinyCTSConfig.h.
 		TinyCTSServerBase.h
 The logic of the Current Time Service server, independent of the Bluetooth stack: the values of the characteristics and the handling of the writes. The classes for NimBLE and for the Raspberry Pi Pico (W) derive from it.
 		TinyCTSTimeSource.h
 Time sources of the TinyCTSServer: the interface, a software clock, the system clock and an adapter for any object with getTimeMs() (e.g. the TinyNTPClient of the TinyNTP library).
 		TinyCTSTypes.h
 The data of the Bluetooth Current Time Service (CTS, 0x1805): UUIDs and the encoding of the characteristics Current Time (0x2A2B), Local Time Information (0x2A0F) and Reference Time Information (0x2A14). No Bluetooth stack is needed: this file is used by the library and the command line tool.
