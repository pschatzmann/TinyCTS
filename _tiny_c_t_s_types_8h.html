Detailed Description

The data of the Bluetooth Current Time Service (CTS, 0x1805): UUIDs and the encoding of the characteristics Current Time (0x2A2B), Local Time Information (0x2A0F) and Reference Time Information (0x2A14). No Bluetooth stack is needed: this file is used by the library and the command line tool.
