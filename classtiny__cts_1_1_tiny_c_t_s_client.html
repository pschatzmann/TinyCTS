Detailed Description

Reads the time from a BLE device that offers the Current Time Service (a phone, a watch, a TinyCTSServer, ...). It is also a TinyCTSTimeSource.

Reads the time from a BLE device that offers the Current Time Service (a phone, a watch, a TinyCTSServer, ...). It is also a TinyCTSTimeSource, so the time can be served by a TinyCTSServer.

This is the version for the desktop. The functions block until they are done. begin() scans for the device, connects, reads the characteristics and disconnects: the time is then extrapolated with the clock of the computer. The getters are in TinyCTSClientBase.

TinyCTSClient cts;
if (cts.begin()) printf("%llu\n", (unsigned long long)cts.getTimeMs());
else fprintf(stderr, "%s\n", cts.getLastError().c_str());

bool tiny_cts::TinyCTSClient::setTimeMs ( uint64_t unixMs)
inlineoverridevirtual

Set the time of the device by writing the Current Time. It works if the device allows it; if it requires an encrypted connection, pair it first.

The time is the one at the moment of the call: the time that the connection needs and half of the round trip time of the write are added.
