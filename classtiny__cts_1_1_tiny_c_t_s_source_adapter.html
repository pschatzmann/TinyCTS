Detailed Description

template<typename T>
class tiny_cts::TinyCTSSourceAdapter< T >

Uses any object with a getTimeMs() method as time source, e.g. the TinyNTPClient of the TinyNTP library:

TinyNTPClient<WiFiUDP> ntp;
TinyCTSSourceAdapter<TinyNTPClient<WiFiUDP>> source(ntp);
