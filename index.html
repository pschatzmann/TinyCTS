TinyCTS

A minimal, header-only Bluetooth Low Energy Current Time Service (CTS, GATT service 0x1805) client and server for Arduino and the desktop, designed for efficiency and portability. It works with the Bluetooth stack of your platform (NimBLE-Arduino, ArduinoBLE, the Pico W core, BlueZ, CoreBluetooth, WinRT). It is the Bluetooth counterpart of TinyNTP: the same ideas, but the time travels over Bluetooth instead of the network.

Features

Client

  • Reads the time from a phone, a watch, a computer or another board that offers the Current Time Service, without a network
  • Minimal resource usage, suitable for embedded/IoT
  • Finds the first device with the service, or the one with a given address or name
  • Returns time as seconds, milliseconds or std::tm struct (UTC and local time)
  • Can set the time of a device that allows it

Time zones

  • The time zone and the summer time offset come with the time (Local Time Information): no time zone table needed
  • The Current Time can be UTC (default) or the local time

Server

  • TinyCTSServer serves the time to the devices around you, from a software clock (TinyCTSClockSource) set by an RTC or GPS, the system time (TinyCTSSystemSource), the TinyNTP client (TinyCTSSourceAdapter); your own sources derive from TinyCTSTimeSource
  • Optionally lets paired clients set the time

General

  • tinycts: command line tool for the desktop (Linux, macOS, Windows) to read the time of a device, serve the time of your computer, set the time of a device and show the time zone of your computer
  • The same classes on ESP32, nRF5, Arduino Nano 33 BLE / Uno R4 WiFi (ArduinoBLE), Raspberry Pi Pico W and the desktop
  • Header-only, easy to integrate
  • cmake support

Quick Start

#include "TinyCTS.h"
TinyCTSClient cts; // the first device that offers the service
void setup() {
Serial.begin(115200);
cts.begin(); // scans, connects, reads the time
}
void loop() {
std::tm tm = cts.getTm(); // UTC; getLocalTm() uses the time zone of the device
Serial.printf("%04d-%02d-%02d %02d:%02d:%02d\n", tm.tm_year + 1900, tm.tm_mon + 1,
tm.tm_mday, tm.tm_hour, tm.tm_min, tm.tm_sec);
delay(1000);
}
TinyCTS.h
Include this file to use the library: Bluetooth Current Time Service (CTS) client and server for NimB...

Call cts.update() from time to time (e.g. once per hour) to stay in sync.

To serve the time to the devices around you:

#include "TinyCTS.h"
TinyCTSClockSource clock_;
TinyCTSServer server;
void setup() {
clock_.setTime(rtc.now().unixtime());
server.setTimeZone(60, 0); // CET (minutes); the second value is the summer time offset
server.begin(clock_, "my-clock");
}
void loop() { server.process(); }

Include TinyCTS.h: it provides everything. All classes are in the namespace tiny_cts, and TinyCTS.h uses it (using namespace tiny_cts;), so you can use the plain class names. If your code has classes with the same names, define NO_TINY_CTS_NAMESPACE before you include TinyCTS.h and write tiny_cts::TinyCTSClient. The Bluetooth stack is selected from the board: see Bluetooth Stacks. Define TINY_CTS_NO_BLE to leave out the Bluetooth classes (code that only needs the encoding of the characteristics or the time sources).

Installation in Arduino

You can download the library as zip and call include Library -> zip library. Or you can git clone this project into the Arduino libraries folder e.g. with

cd ~/Documents/Arduino/libraries
git clone https://github.com/pschatzmann/TinyCTS.git

I recommend to use git because you can easily update to the latest version just by executing the git pull command in the project folder. The Bluetooth library that your board needs is described in Bluetooth Stacks (e.g. NimBLE-Arduino 2.x for the ESP32).
