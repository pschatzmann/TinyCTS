Detailed Description

A BLE peripheral that offers the Current Time Service (0x1805) and serves the time of a time source to the BLE clients (phones, watches, boards with a TinyCTSClient).

A BLE peripheral that offers the Current Time Service (0x1805) and serves the time of a time source to the BLE clients (phones, watches, other boards running a TinyCTSClient, tinycts on the desktop).

This is the version for the desktop. The computer must have a Bluetooth adapter that can be a peripheral. Call process() in your loop: on Linux it handles the requests of BlueZ, on the other systems they are answered by a thread of the system, which also calls the time source. The settings are in TinyCTSServerBase. Only one server per process is possible.

The name of the device is only used on Linux and macOS: Windows advertises the name of the computer.

TinyCTSSystemSource source;
TinyCTSServer server;
server.setTimeZone(60, 0);
if (!server.begin(source, "my-computer")) fprintf(stderr, "%s\n", server.getLastError().c_str());
while (running) { server.process(); sleep_ms(10); }
server.end();

It provides the characteristics Current Time (read, notify), Local Time Information and Reference Time Information (read). While the time source returns 0 (time not known) the Current Time is reported with an unknown date.

begin() starts the BLE hardware (BLE.begin()). Call process() in loop(): it calls BLE.poll(), which handles the requests of the clients. Only one server per program is possible. The settings are in TinyCTSServerBase.

With enableTimeSetting() the writable characteristics need an encrypted connection: ArduinoBLE then asks for it also for reading them.

TinyCTSClockSource clock;
TinyCTSServer server;
void setup() {
clock.setTime(1767225600);
server.setTimeZone(60, 0); // CET
server.begin(clock, "my-clock");
}
void loop() { server.process(); }

It provides the characteristics Current Time (read, notify), Local Time Information and Reference Time Information (read). While the time source returns 0 (time not known) the Current Time is reported with an unknown date.

Call begin() once and process() in loop() if you want periodic notifications (setNotifyInterval()). The settings are in TinyCTSServerBase.

TinyCTSClockSource clock;
TinyCTSServer server;
void setup() {
clock.setTime(rtc.now().unixtime());
server.setTimeZone(60, 60); // CET, summer time
server.begin(clock, "my-clock");
}
void loop() { server.process(); }

It provides the characteristics Current Time (read, notify), Local Time Information and Reference Time Information (read). While the time source returns 0 (time not known) the Current Time is reported with an unknown date.

Select "Tools -> IP/Bluetooth Stack -> IPv4 + Bluetooth". begin() starts the BLE hardware: do not call BLE.begin() yourself. The Bluetooth callbacks read the time source: it must be fast and not block. Call process() in loop() if you want periodic notifications (setNotifyInterval()). The settings are in TinyCTSServerBase.
