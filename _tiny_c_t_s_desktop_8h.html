Detailed Description

The interface between the desktop classes TinyCTSClient/TinyCTSServer and the Bluetooth stack of the operating system: BlueZ (Linux), CoreBluetooth (macOS) and WinRT (Windows). The functions block until they are done; every OS implements the two classes below.
