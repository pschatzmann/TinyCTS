Detailed Description

The server side for macOS: TinyCTSPeripheral on top of TinyCTSCBPeripheral. The requests are answered by the dispatch queue of CoreBluetooth, so process (anonymous_namespace{TinyCTSCoreBluetooth.mm}::CoreBluetoothPeripheral) has nothing to do.
